Privacy: the CPL Library filer

CPL Initiative, California Community Colleges Chancellor's Office. October 6, 2026.

The CPL Library filer is a tool the CPL Initiative uses to file its own decks, films and documents into its own Google Drive. It signs in only as the CPL Initiative's account, works only in that account's CPLLibrary folders, and collects no information about anyone.

When the team files a piece, the filer uploads the file, checks that Google Drive holds the same bytes, and records the file's name and Drive link in the CPL Initiative's catalog of its own work. It reads only the names of the files already in those folders, so that a new version takes the next number. It changes and deletes nothing, and no one outside the CPL Initiative signs in to it.

The filer's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Questions go to the CPL Initiative team at map@rccd.edu.

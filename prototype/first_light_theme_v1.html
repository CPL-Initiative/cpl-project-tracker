Five accents, five jobs

The base is monochrome; color is meaning. Each accent owns one semantic lane and always travels with a glyph. Chips are solid accent fills with white semibold labels — uniform width, button-matched corners, no borders, left-justified. Mustard’s chip is the derived deep ochre (white on true mustard is ~2:1); the bright hue keeps its dot/banner jobs. Neutral data chips stay quiet on purpose — semantics pop, counts whisper.

Accessibility, baked in

Target: WCAG 2.2 AA (a superset of the WCAG 2.1 AA that the DOJ’s ADA Title II rule requires of public entities). Enforced structurally — pre-vetted token pairs + a CI contrast lint — not by vigilance.

  • Color never carries meaning alone — every semantic accent ships with a glyph (▲▼ ✓ ⚠ ⚙ ✨). Saves the crimson/hunter pair for color-blind readers.
  • Glass always carries a scrim — text contrast is computed against the worst-case composite behind it, never the best case. Data tables skip glass entirely.
  • Mustard’s bright hue is never text — chips fill with the derived --mustard-chip ochre under white labels (4.63:1); the bright hue is reserved for dots/banners with ink text (8.77:1).
  • Chips are not buttons — same corner language, but smaller type, no hover, no pointer; only cobalt elements act. Uniform width applies to labeled status chips; glyph-only badges stay compact (chip-fit).
  • Cobalt and violet stay structurally distinct (the one confusable pair): cobalt always with underline/ring affordances, violet always on glyph-badges.
  • OS preferences honored: prefers-reduced-transparency → solid surfaces; prefers-reduced-motion → no reveal animation; prefers-contrast: more → stronger borders + darker muted text.
  • Visible focus everywhere (3px cobalt ring, offset 2px) · interactive targets ≥24×24 px · the First Light dialog is a real role="dialog" with focus trap, ESC, and focus return.
  • Every painting carries hand-written alt text in the manifest — half the curatorial blurb anyway.

The Common SUBJ

Every course identity the CPL Initiative mints begins with a four-letter code. That code is the Common SUBJ, and each MQ discipline has one.

Why it exists

The Minimum Qualifications handbook names the disciplines faculty teach in, from Accounting to Welding. It gives them no codes. C-ID and the Common Course Numbering system have codes, but they cover only the subjects they have reviewed, and many MQ disciplines have no official code at all.

A course identity needs a code all the same. So the Common Subjects Reference assigns one four-letter Common SUBJ to every MQ discipline that has courses, 147 of them today. Each M-ID is minted under its discipline's code: ELMT M10AA is a course in Electromechanical Technology.

How the MQ list decides which codes are needed

The handbook lists 248 disciplines: 81 on the master's degree list, 156 on the list for disciplines without a master's degree, 9 on both, and 2 noncredit disciplines under section 53412. Each one names a faculty area, so each one can need a Common SUBJ.

A discipline needs its code once courses are filed under it. A course reaches its discipline through its subject: the subject map files each college subject code under one MQ discipline. Today 147 disciplines have courses and carry a code. The other 101 receive one when their first course arrives, and a discipline the handbook adds later joins the same way. The MQ list decides how many codes there are and what each one names; the subject map decides which courses each code carries.

How it stays in step with C-ID and CCN

Where an official code already names the subject, the Common SUBJ takes it. Thirteen disciplines carry the CCN code and twenty the C-ID code. Only where no official code exists does the reference mint one, as it has for 114 disciplines. Those read as proposed until a C-ID or CCN code names their courses.

The four-letter shape holds even when an official code is shorter. C-ID names Administration of Justice AJ; its Common SUBJ is CRIM, and the List shows the C-ID code beside it as an official code that differs. Twenty-three disciplines show one today. The two codes stay linked and visible, so a reader can always find one from the other.

The CCN's fourteen subjects are all four letters. Of C-ID's sixty-five prefixes, forty-four are; the other twenty-one run from two characters to five, such as AJ, KIN and AG-AB. C-ID sets its own codes. If those prefixes move to the CCN's four-letter standard, the Common SUBJ and the official code will read the same in more disciplines, and the reference will follow them.

How it stays in step with the colleges

Colleges type their own subject codes into COCI, and one course can carry several of them. Those local codes are the best evidence of what a discipline is called on the ground. For a minted code, the reference looks first at the code the most colleges use. A pick that departs from it carries a note saying why, and the nightly scan asks for that note when it is missing.

Diesel Mechanics carries AUTD. Its courses arrive under thirty-one local codes. DIES is used by four colleges; DCDT has the most courses, all at one college. The count of colleges says more about common use than the count of courses.

One code, one discipline, with two recorded exceptions

A Common SUBJ belongs to exactly one MQ discipline, so two disciplines never share a code by accident. Two kinds of sharing are ruled and recorded. An alias family is one discipline the handbook lists under two names, and it carries one code. An umbrella code covers a family of related disciplines; Foreign Languages carries FLNG beside a code for each language. Both are written down, so neither reads as a collision.

What this means when a code changes

The Common SUBJ is the key every M-ID is minted under. Changing it re-keys every M-ID in the discipline at the next fold, so a change follows the re-mint playbook and earns its cost. A good code agrees with three things at once: the MQ discipline it names, the C-ID or CCN code where one exists, and what colleges already call these courses. Check alignment, on the List's edit row, runs that test on one code before you save it.

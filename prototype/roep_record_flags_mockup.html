What Confirm and Needs a fix would write
  1. Only a reviewer signed in with the magic link sees the two buttons. Everyone else sees the flags and the drafts.
  2. Either button calls one database function, program_record_verdict_add, which adds a row to a new log, program_record_verdicts: the record, Confirm or Needs a fix, the note, who, when, and the fingerprint of the requirements the page showed.
  3. Confirm marks the record checked only when that fingerprint still matches the record and its three machine checks pass. A rerun that changes a block clears the mark until someone reads the record again, as it does today.
  4. Needs a fix leaves the record unchecked and adds the note to the college's reading procedure as an open question, so the next run carries it out. No one edits a record by hand.
  5. The log keeps every verdict. Undoing one adds a new row, and the record's checked mark always follows the latest verdict.

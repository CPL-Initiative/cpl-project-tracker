Subjects and Disciplines

A course on the Common Course Reference carries a subject and a discipline. They are different things, they come from different places, and one is derived from the other. This page says which is which.

The two words

Subject
A four-letter code. PSYC, WELD, ENGL. It is the first part of a course identity: PSYC C1000. Every identity has one.
Discipline
A faculty area from the state Minimum Qualifications list. Psychology, Welding, English. It decides which faculty may teach the course, and it is what SkyView draws an island for.

Every subject belongs to one discipline. A discipline can carry several subjects. Foreign Languages carries one per language. So the relationship runs many subjects to one discipline, never the other way.

How a course gets its discipline

Read the chain from the course identity down. Each step names the file that answers it.

  PSYC C1000   Introduction to Psychology
  ----+-----
      |
      |  the first token IS the subject
      v
  PSYC                                        the subject
      |
      |  kb/reference/subject_discipline_map.json
      |  314 entries, one discipline each
      v
  Psychology                                  the discipline
      |
      |  kb/discipline_canonical_subj4.json
      |  147 disciplines, one canonical code each
      v
  PSYC                                        the Common SUBJ

The last step looks circular and is not. The first arrow answers which discipline does this subject belong to. The last answers of the several subjects this discipline carries, which one is canonical. Two questions. Two files. For Psychology the answer is the same code both times, which is why the chain above looks like it doubles back.

Foreign Languages shows the two questions coming apart. The subject map files nine codes under it, among them SPAN, FREN, GERM and JAPN. Its canonical code is FLNG, which is none of them. So a Spanish course has subject SPAN, discipline Foreign Languages, and Common SUBJ FLNG: three values, all correct, none of them redundant.

Local codes are not the subject

Colleges type their own subject codes into COCI. Those codes are on the row, and they are not the SUBJ4. One identity can carry five of them.

  ARTF M1003
  ----
   |                        local codes the colleges typed:
   |                          AHIS   ART   ARTF   ARTH   ARTHIST
   v
  ARTF  -->  Art            the subject is the id prefix, and it is the one that resolves

The hover on the Common Course Reference calls these Local SUBJ code(s), which is what they are. Reading them instead of the id prefix files a course under the wrong discipline, or under none.

What happens when a step is missing

No discipline means no Common SUBJ

The Common SUBJ is looked up by discipline. A course with no discipline has nothing to look it up by, so that column stays blank too. One missing value shows up as two.

Until 8 September 2026 this happened to most courses that carry an official identifier. The five passes that infer a discipline all read one file, and that file holds M-IDs only, so a C-ID or a CCN was never seen by any of them.

Nothing about a C-ID makes a course harder to classify. The gap tracked where the row came from, not what the row was.

What changed

The generator now fills a blank discipline from the subject map, and from the identifier reference where the map has no entry. It fills blanks only, so a curated discipline still wins, and every fill records which file answered. Blank identities went from 326 to 93.

SkyView's subject table used to work out a subject's discipline by taking the most common discipline among its own courses. When those were blank the answer was blank, and the table said no discipline yet as though that were a fact about the subject. It now reads the subject map first and says on each row whether the map or the courses answered.

Who decides

DR-25 in the governance register, owner Sam. It covers which file is authoritative for the subject to discipline edge, who may change a mapping, and what happens to the rows downstream when one changes. Before it existed, four files wrote this relationship in two directions and none of them had an owner.

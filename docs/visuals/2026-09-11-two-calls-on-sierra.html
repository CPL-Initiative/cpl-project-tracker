1 · Should Sierra reason privately before she answers?

Decided 2026-09-11, Sam: off, as proposed. “Let’s keep it off but test for better options if they exist. Currently, it’s giving fantastic answers!” Any trial of reasoning runs on the preview copy first.

What this is
The model behind Sierra can work through a question privately before it writes the reply. Nobody sees that work. It is billed as output, it counts against the same length allowance as the answer, and while it runs the widget shows Thinking… with three dots and no words. Until September 10 Sierra never did this. Sonnet 5 turns it on unless the request says otherwise, and that is what produced the blank answers: on broad questions the private reasoning used the whole allowance before the first word. Since 02:03 UTC on September 11 the request says off.

2 · How long may an answer run?

Decided 2026-09-11, Sam: 8,192. “Let’s make it high for now so folks playing around with it always get a complete answer.” Shipped as the stop in the request; with reasoning off only the answer itself reaches it.

What this is
Every answer has a hard stop, set at 2,048 tokens since Sierra launched. A token is a piece of a word, about four characters on the models Sierra ran on before. Sonnet 5 counts about a quarter more tokens for the same text, so the same stop now lands at about 6,000 characters instead of 8,000. When an answer reaches the stop it ends mid-sentence, and until this week nothing recorded that it had. The stop is a ceiling, not a spend: a short answer costs what it uses, and the ceiling matters only to long ones.

Cost. The output part of one answer at each ceiling, worst case: 2,048 tokens is two cents; 3,072 is three; 4,096 is four; 8,192 is eight. A typical answer uses about one cent whatever the ceiling.

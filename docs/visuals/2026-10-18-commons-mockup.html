How to read a row

  • The pair is each reference's own definition of complete, and the word beside it says the test behind the count: a machine check, a curator's stamp, the auditor's score, an assignment by rung. Each row's complete is its own kind of count, so a percentage stays inside its row and no column sorts on it.
  • Every known issue names the actor who can close it: a procedure, the harvest, a curator, or Sam. A cause sits in the parentheses. In the build a count opens the list it totals in the reference's tab.
  • Two stamps, apart: the machine stamp is the last run of the thing that writes the data, read against its declared cadence; the session stamp is the last time a session wrote the reference's run log. A stamp past its cadence reads stale. A reference with no run log says so, and a file that fails to load reads could not be read.
  • A call waiting on Sam is read from the decision sheet's own store, so an answered card leaves the row the moment he answers, and the row names the last card answered.

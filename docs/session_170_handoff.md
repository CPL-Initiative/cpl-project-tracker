## Patterns that worked

- **State the best outcome for each question before reusing a tool.** That one
  check is what caught that this was a different instrument.
- **Search the COURSE catalog, not just the program inventory.** Delta's plumbing
  apprenticeship (`A CON 87A–90D`) sits under no plumbing-named program and the
  prefix reads as *construction*. A program-only search returns "no plumbing".
- **Write the guard the moment you catch one instance by hand.** Manual review
  found 2 over-claims; the guard immediately found 4 more.
- **Verify a guard by making it fail.** A deliberate false claim was injected and
  the non-zero exit confirmed before trusting it.

## Safety patterns to honor

- **Rule 7 — TOP is a last-in-line corroborator.** Nothing here gates on TOP; keep
  it that way if you extend the matching.
- **Absence has two meanings and they must not collapse.** *No exhibit anywhere*
  (build) vs *exhibit exists, this college not listed* (adopt) — same empty cell,
  opposite next step.
- **Never let authored prose assert something you compute.** `check_absence_claims()`
  is a hard failure by design; do not downgrade it to a warning.
- **Narrative copy is a FINDING** and lives in the offering map's `_narrative`, not
  in the generator. The generator refuses to run without one.
- ⚠️ **`recalc.py` cannot run in this sandbox** — LibreOffice times out even on a
  one-formula file. Workbook formulas here were verified by matching each COUNTIF
  criterion against actual cell values instead. Do the same, and say so.

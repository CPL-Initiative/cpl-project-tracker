# A sign-in form is no proof of a closed system, and a catalog host is no proof of a public outline

**The learning.** When a census classifies a web system by its front page, it measures the front page. To know whether a system serves a thing in public, open one instance of the thing.

**How it showed (S373, 2026-10-12).** The course outline census's run 2 recorded a host for 59 of 118 colleges and called 8 of them sign-in. Most hosts it recorded were the college's catalog, and its "prints SLOs" flag matched menu items and "Cal Poly SLO". A probe that followed one more link found that curriQunet's dashboard, which carries a login form, lists a public outline report for every course, and that RCCD's, SDCCD's and Cuesta's outlines print student learning outcomes. Run 5, which opens one course's outline on every host, found an outline at 32 colleges, 18 printing SLOs.

**The method.**
1. Classify access by what a page links and serves, not by whether it shows a password field: a page that links one item's public report is public.
2. Count a heading only where it starts its own line and has text under it; a menu item or a sentence that names the heading in passing is not one.
3. Read the whole page when the thing sits deep in it; a reader that keeps the first few thousand characters misses an outline's outcomes.
4. Record unknown as unknown: where no instance was reached, the flag is null, not false.

**Where it applies.** Any census of public systems (catalogs, outline systems, program mappers) whose findings feed a decision about who to ask for access.

  misread (the "Generated by" filter = discipline provenance, not identity; the credit/
  noncredit chips = `credit_mixed`/`ncc_mixed`, not "has credit"; `r.subj` local vs `subj4Of`
  canonical). Clarifying first changed the right fix. Sam values this ("thanks for recentering me").
- **One focused PR + one committed jsdom test per ask** — six clean PRs, merge-on-green via a
  ~110s background-`sleep` timer that re-invokes on the secret scan. Caught + fixed 3 count-format
  regressions because the test ran the FULL suite.
- **Fan parallel read-only Explore agents to ground a scope doc** in the real machinery before writing.
- **The merge is durable on click; per-click regen is infeasible** — don't gold-plate; the cron/
  dispatch publishes downstream, the overlay tracks live.

## Safety patterns to honor
- **Merge-on-green** (clean OR unstable) for your own engineering PRs; let the scan finish, then squash.
- **Code-only PRs**; the post-merge `daily-dashboard.yml` dispatch publishes regenerated artifacts.
- **CCR = static `unified_courses.js`** (NOT pipeline-regenerated); its DATA is `unified_courses_data.js` (regenerated).
- **A re-mint is a full Rule-7** — dry-run → alias map → re-key memberships/articulations/**promotions**/Supabase → atomic land. Never skip `_rekey_promotions.py`.
- **Stop-hook drift:** the container keeps reverting `~/.claude/stop-hook-git-check.sh` to a pre-fix
  version → it false-flags GitHub squash-merge + cron commits on `main` (DO NOT amend, Rule 5).
  Re-seat with `cp scripts/stop-hook-git-check.sh ~/.claude/` when it nags.

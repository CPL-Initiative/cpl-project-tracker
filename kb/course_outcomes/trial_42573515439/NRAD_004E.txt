Catalog Description Prepares the RN student for the state licensing exam. Presents critical thinking strategies required to answer NCLEX questions. Includes hands-on computer testing to simulate the state board testing format.
Schedule Description Prepares the RN student for the state licensing exam.Includes hands-on computer testing to simulate the state board testing format. Corequisite: NRAD 204B (Formerly NRAD4E)

Student Learning Outcomes
Demonstrate knowledge of the application process for licensure exam (NCLEX).
Apply knowledge from nursing school to analyze NCLEX questions and identify the best answer.
Demonstrate familiarity and increased confidence when taking the NCLEX computerized exam.

Assignments:
Independent Work (minimum 2 examples):
Complete multiple test questions on a computer simulating national license exam format.
(Obj 1, 4, 5, 6)
Independent Work (minimum 2 examples):
Complete multiple choice test questions from NCLEX review books.
(Obj 1, 6)
Critical Thinking Assignments (minimum 2 examples):
Students will participate in classroom discussions to provide rationale for correct and incorrect multiple-choice test options.
(Obj 1, 3)
Critical Thinking Assignments (minimum 2 examples):
Students will be presented with a clinical situation and asked to identify the best answer from four possible options requiring them to use the nursing process and prioritize patient needs.

CATALOG COURSE DESCRIPTION:
This course is a hands-on study in creative problem-solving using fundamental concepts of computer science and artificial intelligence. The course introduces three major programming paradigms: Object-Oriented programming, Functional programming and Logic programming; and how to solve problems using each of 
them. Topics include logic, designed and learning algorithms, data types & data structures, functions & lambdas, classes & objects, neural networks, abstraction, recursion, input/output (I/O), and graphical user interfaces. This course is designed for students majoring in computer science, artificial intelligence, game or web development, and for anyone interested in software development or artificial intelligence in general.

STUDENT LEARNING OBJECTIVES:
Upon successful completion of the course the student will be able to:
Upon successful completion of the course the student will be able to:
Describe computers and artificial intelligence in a historical, socio-economic, or societal context.
Explain the evolution of computer science through the increasing use of abstraction.
Explain the evolution of artificial intelligence from logic and expert systems, and neural networks to large language models (LLMs).
Distinguish between functional, logical and object- oriented approaches to programming.
Define and employ atomic data types, such as booleans and numbers, and compound data types, such as lists, arrays, and user-defined compound data structures.
Differentiate between code versus data modalities.
Formulate functions that capture key abstractions, prevent duplication of code or data, and transform parameters and return values.
Employ object oriented programming methodology to define classes using data encapsulation, and create and manipulate objects.
Create code that accepts input from the user and produces output to the user.
Use conditional logic to determine program outcomes.
Practice the display of data through parameterization.
Describe and recognize how a problem can be decomposed into self-similar subproblems as a means of developing a recursive algorithm.
Explain how computer programs can be created systematically.
Use logical constructs and recursion to operate upon data structures.
Explain how a programming language can be extended to create a vocabulary that is proximal to the problem domain.
Create animations and implement an interactive graphic game.
Systematically design and implement introductory-level programs from given specifications, such as problem descriptions, user stories, design criteria, input/output scenarios, functional or unit tests, pseudo code, modeling language specifications or diagrams.
Articulate the purpose and working of introductory-level programs, and their language constructs and data structures, such as through diagrams (for instance, flowcharts, Unified Modelling Language (UML) diagrams or entity-relationship (ER) diagrams), code comments, screencast videos, interactive computing notebooks (for instance, Jupyter notebooks), or other written or oral communication.
Document external interfaces of introductory-level functions or methods (the application programming interface (API)), and the inner working of introductory-level functions, or methods in-code comments.
Systematically test and debug introductory-level programs by interactively entering arguments, utilizing functional or unit tests, running programs in a test environment, or using a debug environment (for instance, a debugger in an integrated development environment (IDE)).
Develop introductory-level programs using industry recognized tools, such as code editors, command lines (Read, execute, print loop, REPL), emulators, or integrated development environments (IDE).
Create a fully functional, interactive introductory-level program incorporating a substantial set of topics from the course.
Use declarative constructs, including functions, in a programming language from the Lisp family to understand a problem and to create a solution.
Express a problem as a set of logic clauses in the programming language Prolog and use them to solve a problem.
Create, train and use an artificial intelligence algorithm to classify data.

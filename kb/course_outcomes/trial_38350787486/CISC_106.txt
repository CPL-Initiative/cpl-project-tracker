Catalog Description
This course is a hands-on study in creative problem-solving using fundamental concepts of computer science and artificial intelligence. The course introduces three major programming paradigms: Object-Oriented programming, Functional programming and Logic programming; and how to solve problems using each of 
them. Topics include logic, designed and learning algorithms, data types & data structures, functions & lambdas, classes & objects, neural networks, abstraction, recursion, input/output (I/O), and graphical user interfaces. This course is designed for students majoring in computer science, artificial intelligence, game or web development, and for anyone interested in software development or artificial intelligence in general.

Course Description
This course is a hands-on study in creative problem-solving using fundamental concepts of computer science and artificial intelligence. The course introduces three major programming paradigms: Object-Oriented programming, Functional programming and Logic programming; and how to solve problems using each of them. Topics include logic, designed and learning algorithms, data types & data structures, functions & lambdas, classes & objects, neural networks, abstraction, recursion, input/output (I/O), and graphical user interfaces. This course is designed for students majoring in computer science, artificial intelligence, game or web development, and for anyone interested in software development or artificial intelligence in general.
